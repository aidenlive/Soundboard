## How to join

The repository is private. Ask the owner for access, then:

1. Read [AGENTS.md](AGENTS.md) (it applies to people too) and [docs/README.md](docs/README.md).
2. Branch from `main`, one branch per change: `fix/…`, `feature/…`, `docs/…`.
3. Run `make validate` until it is green.
4. Open a pull request with the template in `.github/`. The owner merges to `main`.
