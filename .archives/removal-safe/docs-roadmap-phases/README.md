roadmaps would state the same facts twice.

**What replaced it:**

- Phases 1 to 3 → versions 0.3.0 to 0.5.0 in [ROADMAP.md](../../../ROADMAP.md), with the same
  exit tests and risks.
- Phase 0's exit test and the on-device validation matrix → [docs/guides/qa.md](../../../docs/guides/qa.md)
  and version 0.2.0 in the roadmap.
- Phase 0 and Phase 1 "done" lists → [CHANGELOG.md](../../../CHANGELOG.md) 0.1.0.

**Safe to restore:** yes, but it would duplicate `ROADMAP.md`; update that file instead.
